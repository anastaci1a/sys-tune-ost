# sys-tune-ost

Nintendo Switch system UI soundtrack manager with a resident sysmodule and
Tesla/Ultrahand overlay, forked from [HookedBehemoth/sys-tune](https://github.com/HookedBehemoth/sys-tune).

Project documentation is in **[docs/](docs/README.md)**: start with the
[user guide](docs/USAGE.md), [architecture](docs/ARCHITECTURE.md), or
[bugs and TODOs](docs/TODO.md). Agent procedures are in **[AGENTS.md](AGENTS.md)**.

The qs11 implementation uses IPC API 18. Experimental detection and an
intermittent freeze/fatal still have outstanding console validation.
Build and installation instructions are in [docs/BUILD_AND_RELEASE.md](docs/BUILD_AND_RELEASE.md).
